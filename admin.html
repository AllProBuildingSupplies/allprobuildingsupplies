CSV upload guide
Bulk Upload / Replace replaces the entire online catalog with the file (items missing from the CSV are removed). Quantities are overwritten, not added.
Receive Shipment CSV only adds stock. Export Inventory → fill AddQty with pieces received (leave Qty as reference) → upload Receive.
Safest format: click Export Inventory CSV and edit that file — headers match exactly what upload expects:
Material, Code, Tommur-Code, Lesso-Code, Description, Size, Pack, Qty, AddQty, Price, Image, main_category, sub_category, sub_sub_category, sub_sub_sub_category
Required for Replace: Code, Description, Size, Pack (pcs/carton), Qty, Price, Image. Category columns and factory codes are optional but keep filters working.
Decimals / sizes: 1.5 = 1-1/2 (same SKU). Reducers: 2x1.5 = 2x1-1/2. Prefer decimals in Excel so sizes are not turned into dates. Whole sizes (2, 3, 4) are fine as-is.
Prices: dollars with up to 2 decimals (e.g. 12.50). Empty price → $0.00 / out-of-stock style display. Do not include $ or commas in the Price cell.
Images: site-relative paths like images/Elbow.png (not a full URL). Save CSV as UTF-8 when possible (Excel “CSV UTF-8”).
