# PVC + PEX — should we leave China?

Short answer: **no as the primary mill.** Keep Tommur / Lesso for the 45'HQ catalog. **Yes, get three backup quotes** (India ASTM mills, Mexico Wavin, Vietnam only if they will run US inch + NSF). That is a tariff hedge, not a cheaper-FOB hunt.

This is different from glass. Glass has China/Malaysia **AD/CVD** that makes those origins unusable. Plastic PVC/PEX pipe (HTS **3917**) has **no AD/CVD order**. China is still legal. The issue is stacked **Section 301** on China-origin articles, plus whether another country can even make the **US inch SKU tree** we already sell.

## What we actually buy

From `Factory_Order_PVC_PEX_45HQ.csv` and the live plumbing catalog:

- **PVC Sch 40** pipe (solid + foam-core), IPS inch, ASTM D1785
- **PVC DWV fittings** (¼ / ⅛ / 1/16 bends, street, wyes, couplings, etc.), ASTM D2665
- **PEX-B** pipe + elbows/reducers, **CTS** (½" / ¾" / 1"), ASTM F876 / F877

That fittings mix is the money. A mill that only extrudes 4 m metric uPVC sticks is useless for this container.

## Why China still wins FOB and SKU coverage

China (Lesso via Tommur) is still the only origin that has already proven:

- Full **US plumbing** size tree (not ISO 4422 / EN 1452 metric)
- **NSF** listings for potable / DWV
- Foam-core + a deep DWV fittings catalog that fills a 45'HQ
- PEX-B in **CTS**, not 16/20/25 mm
- Export infrastructure (cartons, docs, 45'HQ stuffing) we already use

India, Vietnam, and Turkey are large pipe industries. Most of that capacity is **domestic/ASEAN/EU metric**. Cheaper FOB on the wrong standard is a wasted RFQ.

## Why it is still worth quoting elsewhere

China-origin HTS 3917 typically stacks:

| Layer | China | Vietnam | India | Turkey | Mexico (USMCA qualifying) |
|---|---|---|---|---|---|
| MFN (pipes ~3917.21 / fittings ~3917.40) | ~3.1% | ~3.1% | ~3.1% | ~3.1% | **0%** |
| China Section 301 (List 3 on plastic articles) | **~25%** | — | — | — | — |
| Forced-labor 301 overlay (CBP CSMS #69326983, Jul 24 2026) | **12.5%** | 12.5% | **10%** | 12.5% | **exempt if USMCA** |

Confirm stacking with the broker before you change a PO. If those layers all apply, China can be **~40%** duty vs **~13–16%** India/Vietnam/Turkey vs **0%** Mexico. A mill that is 15–25% higher FOB can still **land cheaper**.

There is still **no** reason to abandon China the way we abandoned China glass. Quote in parallel. Switch only if landed + NSF + the DWV fittings tree actually beat Tommur.

**Easiest origin shift (do this first):** ask Tommur / Lesso whether the **same ASTM molds** can be run and **invoiced** from a non-China Lesso plant (Vietnam trading co. exists; Indonesia/Thailand Lesso plants exist). Origin follows where the pipe is extruded, not the sales office. If they can change origin without a new mill qualification, that beats starting over with Binh Minh.
